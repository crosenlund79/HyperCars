## Game decisions (user-confirmed only)

- **Game title:** HyperCars (user)
- **Godot version (pin minor, e.g. 4.x):** 4.7.x — developed and tested with 4.7.2-stable, GL Compatibility renderer (user, 2026-11-14)
- **Premise / core player loop:** Undecided
- **Perspective / art direction:** **Approved 2026-11-14 (user, "HyperCars — Approved Visual Direction").** Top-down view. Original, modern, hand-painted HyperCars identity; do **not** reproduce the original Super Cars II pixel art.
  - **Style reference:** the user's own *Fluffy Bears of Doom* drawings in `docs/art_refrence/` (folder name as committed): `bomb`, `chair`, `clown`, `duck`, `effects`, `fluff`, `powerups`, `tiles` (`.png`).
  - **Study only their artistic characteristics:** hand-painted textures, soft brushwork and organic outlines; slightly imperfect, asymmetrical shapes with personality; soft shading, highlights and subtle surface texture; their colour choices, proportions and playful character. **Never recreate or incorporate the depicted objects** (bomb, furniture, bear, chest, clown, duck, etc.).
  - **Applies to** original HyperCars artwork: top-down cars, tracks, terrain, obstacles, weapons, interface elements and other assets as required.
  - **Asset rules:** `template_` graphics must be proper, visually appealing art, not programmer placeholders; all assets stay stylistically consistent so the user's drawings can replace them one at a time; user artwork has priority and missing custom assets fall back to Claude's templates through the existing `custom/` override contract (`assets/README.md`), including replacement in exported Windows/Linux games without rebuilding; consistent dimensions, transparency, alignment and animation/sprite-sheet layouts must be defined; create only assets needed for approved iterations.
- **Confirmed mechanics and constraints:** Gameplay remains mechanically faithful to Super Cars II (1991, Amiga); graphics follow the approved visual direction above (user, 2026-11-14). Controls as confirmed by the user from the original manual (2026-11-14): joystick left/right steer; two control modes — *Fire to Accelerate* (fire held accelerates, releasing fire brakes automatically) and *Fire to Brake* (automatic acceleration, fire held applies stronger braking); joystick up/down fire front/rear weapons, never brake. All physics values are provisional until calibrated against the original. **M1 handling is the approved baseline** (user, 2026-11-14, M1.1+M2 brief): any change to driving physics needs user approval. Original race rule reported by the manual and applied where relevant: the finishing order reverses the next race's grid (winner starts last). **Recurring rivals** (user, 2026-11-14, M2.1): racer ids 1–9 are fixed identities in every race and session — Victor "The Professor", Rocco "Mad Dog", Ellie "Sparrow", Hank "The Wall", Maya "Ghost", Dante "Showboat", Greta "Clockwork", Finn "Wildcard", Nina "The Hunter" (`src/ai/rival_roster.gd`).
- **Explicitly out of scope:** Undecided
- **Existing modules / boundaries (M1, M1.1, M2):**
  - `src/driving/` — `CarModel` (pure deterministic driving model; symmetric car-to-car contact), `DrivingParams` (provisional tunables, `default_driving_params.tres`), `Car` scene (physics body, wall and car contacts).
  - `src/track/` — `TrackLayout` (straights + per-corner radii, starting grid; `circuit_01.tres`), `ClosedPath` (arc length/projection), `Track` (builds ground, road, barriers, start line, checkpoint gates, grid slots; emits `checkpoint_reached`).
  - `src/race/` — `LapTracker` (in-order checkpoint laps), `RacerState`, `RaceSession` (mode select → racing → finished; spectator participation; race clock runs until every car finishes; field standings, finishing order, reversed grid), `RaceProgress` (continuous distance for live positions).
  - `src/ai/` — `RacingLine` (line + speed profile from shared driving params), `AiDriver` (player-equivalent inputs: digital steer + fire; seeded personality decisions), `AiParams` (provisional; neutral `default_ai_params.tres`, pilot personalities in `personalities/`), `RivalRoster` (fixed identities).
  - Spectator (M2.1): `RaceHistory` (`src/race/`, session-only results and position counts), `SpectatorDirector` (`src/camera/`, battle-following camera), `HistoryPanel` (`src/ui/`); spectator flow and simulation speed in `src/main/main.gd`.
  - `src/controls/` — `PlayerControls` (input actions, digital joystick reading). `src/camera/` — `FollowCamera`. `src/ui/` — `Hud`.
  - `src/assets/` — `AssetResolver` (override/fallback), `AssetCatalog` (replacement contract). `src/main/` — composition root; no Autoloads.
- **Testing framework (GUT or GdUnit4) and commands:** GUT 9.7.1 (vendored in `addons/gut/`; user, 2026-11-14). Run all tests headless from the project root: `godot --headless --path . --import` once, then `godot --headless --path . --fixed-fps 60 -s addons/gut/gut_cmdln.gd` (config: `.gutconfig.json`; engine errors and `push_error` fail tests; `--fixed-fps 60` simulates the AI races in ~3 s instead of ~1 min in real time — both pass). Manual checklists: `tests/manual/m1_driving_checklist.md`, `tests/manual/m2_racing_checklist.md`, `tests/manual/m21_spectator_checklist.md`.
- **Target platforms:** Undecided (runtime asset overrides currently cover Windows/Linux only; other platforms need an explicit decision)
- **Asset override notes:** Runtime `custom/` folder overrides required; see `assets/README.md`. Per-asset replacement contract lives in `src/assets/asset_catalog.gd`: overrides are PNG, may be any resolution but must keep the template's aspect ratio and orientation; the game scales them to a fixed display size. M1 assets (template px → display): `cars/car_player` 128×72 → 64×36 (nose right, centred, transparent); `track/tarmac`, `track/grass` 256×256 seamless, one tile = 256 world px; `track/wall` 128×32 strip seamless left-right, 20 px wide; `track/start_line` 32×128, stretched across the road; `ui/hud_panel` 96×96 nine-patch, 24 px margins. M2 adds `cars/car_ai_1` … `cars/car_ai_9`, same contract as the player car (car n = rival n). M2.1 adds `ui/star_gold`, `ui/star_silver`, `ui/star_bronze` 48×48 → 22×22 (square, centred, transparent). `docs/.gdignore` keeps the art references out of Godot imports.
